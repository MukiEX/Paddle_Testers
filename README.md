# Paddle Testers

Controller test programs for checking paddle, spinner and mouse-style controllers on retro consoles. Each one shows a live diagram per player plus an X-axis bar, and detects controllers with the same rules as the matching Paddle Edition patch.

| Folder | Platform | Image |
|---|---|---|
| [`ps1/`](ps1/) | PlayStation | BIN/CUE: pad, DualShock, PS Mouse, NeGcon, Namco Volume, JP3 spinner on the d-pad |

Each folder builds on its own; see its README.
